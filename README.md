## Featured Projects

### South Telecom Internship – Worldfone4X Cloud

Contributed to a full-stack CRM/CXM platform supporting ticketing, mailbox, scheduling, automation, reporting, and other business workflows.

**Key Contributions:**
- Developed PHP controllers, MongoDB operations, permission-aware APIs, and reusable integrations
- Improved frontend workflows using JavaScript, Ajax, jQuery, and Kendo UI
- Increased PHPUnit coverage to 98–100% across targeted PHP/CodeIgniter modules
- Reduced duplicated logic while preserving existing API behavior

**Tech:** PHP, CodeIgniter, MongoDB, JavaScript, Ajax, jQuery, Kendo UI, PHPUnit

### Abbott Internship – Data Analytics

Automated data preparation and analyzed large-scale purchasing data for Abbott's CRM team.

**Key Contributions:**
- Improved data cleansing and visualization efficiency by 30%
- Analyzed over 100,000 purchase records to identify product and market trends
- Produced insights supporting inventory forecasting and business decisions

**Tech:** Python, SQL, Power BI, Data Analysis, Data Visualization

### NUSHub

A full-stack campus forum where NUS students can create posts, comment, vote, search, and filter discussions.

**Key Contributions:**
- Built RESTful APIs for users, posts, comments, votes, and reports
- Implemented JWT authentication and BCrypt password hashing
- Integrated an OpenAI-powered answer box for campus-related questions
- Developed responsive search, moderation, and discussion features

**Tech:** React.js, Tailwind CSS, Node.js, Express.js, PostgreSQL, JWT, OpenAI API

### MealMatch

A full-stack meal-planning application for personalized weekly plans, ingredient inventory, and grocery optimization.

**Key Contributions:**
- Designed a recommendation engine using cost, cooking time, diet, nutrition, and available ingredients
- Generated shopping lists by comparing recipes with users' existing inventory
- Built dashboards, recipe filtering, inventory management, and AI-powered suggestions

**Tech:** TypeScript, Next.js, Node.js, Express.js, PostgreSQL, Render
